# Library Demo Run Guide

## Prerequisites

- Python 3.9 or later
- A terminal opened in the repository root directory

## Run the demo

From the repository root, run:

```bash
python3 run.py demo
```

On Windows, if `python3` is not available, use:

```bash
py -3 run.py demo
```

## What the demo does

The demo starts the library application with sample data and demonstrates catalog searching and library borrowing behavior.
